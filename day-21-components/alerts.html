Alerts

Alerts tell people what just happened. Every alert here uses the same base class, alert, plus one variation class that only changes the colours.

Tips for Alerts

Colour should never be the only clue as to what it's about. Each alert should also have an icon and a word, because not everyone can tell red from green.

The message should be useful. A good alert says what happened and what to do next.

New variations should be easy to make. All you need to do is copy one variation in styles.css, rename it, and change three colours.
