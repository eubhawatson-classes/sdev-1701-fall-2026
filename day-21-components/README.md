# CRAP

CRAP comes from Robin Williams' The Non-Designers Design Book first published in 1993. 

## C: Contrast

If two thing are different, make them _obviously_ different. 

This is all about establishing a visual hierarchy (i.e., making it immediately apparently what the most important things on the page are). It can be achieved with a contrast in size, colour, boldness / line thickness, and spacing. 

## R: Repetition

Pick a style and reuse it everywhere.

CSS custom properties and web components are great examples of repetition in design. Every card should get the same corner radius and every link should get the same colour. This allows the user to predict the behaviours of each element on the page, and visually draw the relationship between like things. 

## A: Alignment

Nothing gets placed on a page arbitrarily. Everything lines up with something else. 

A great example of a UI that uses alignment to help infer relationships is in code editors. For example, properly indented HTML will help relay parent-child and sibling relationships between elements. 

On the page, we generally use tools like flexbox or even borders to make sure that things align properly. The justification of large blocks of text is also very important to make sure that text remains legible. 

## P: Proximity

Related things sit together, and unrelated things get space between them. 

The amount of space between visual elements implies their relationship. A label should sit close to its form control, and space _within_ a group should be smaller than space _between_ groups.
