UI components

Components are the puzzle pieces of a website: small, reusable parts that people already know how to use. Each page below shows one piece.

Every page shares the same stylesheets, so you can copy a component's HTML into any page and it'll look and work the same. This is the main idea behind component-based design and reusable code.

  • Buttons

    A link dressed up as a button, with hover, focus, and active states.

  • Navbar

    Brand on the left, links on the right, and the current page marked.

  • Search Form

    A labelled search box that reuses the button.

  • Alerts

    One base class and four variations: info, success, warning, and error.
